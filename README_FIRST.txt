PORTFOLIO ISMAIL JAROUI
========================

1) Pour ouvrir le portfolio:
   - Double-cliquez sur OUVRIR_PORTFOLIO.bat
   OU
   - Double-cliquez sur index.html

2) Pour ajouter vos coordonnées:
   - Ouvrez assets/js/config.js avec VS Code
   - Remplissez email, whatsapp, github et linkedin
   - WhatsApp doit être écrit sans + ni espaces.
     Exemple: 212612345678

3) Pour modifier les textes:
   - Ouvrez index.html dans VS Code
   - Utilisez Ctrl+F pour trouver le texte à remplacer

4) Pour publier gratuitement:
   - GitHub Pages, Netlify ou Cloudflare Pages conviennent à ce portfolio statique.

IMPORTANT:
Les prix affichés sont des prix de départ indicatifs. Vous pouvez les modifier dans index.html.
